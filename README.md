# Парсер вакансий с HeadHunter

## Описание

Проект представляет собой консольное приложение для поиска вакансий на платформе HeadHunter через API, сохранения данных
в базу данных PostgreSQL и последующего анализа с помощью различных методов фильтрации и сортировки.

## Функциональность

+ Получение вакансий с API HeadHunter по ключевому слову

+ Фильтрация вакансий по определенным компаниям

+ Сохранение данных в PostgreSQL

+ Просмотр статистики по компаниям и вакансиям

+ Поиск вакансий с зарплатой выше средней

+ Поиск вакансий по ключевым словам в названии

## Установка и настройка

### 1. Клонирование репозитория

```aiignore
git clone https://github.com/Aleksei-Pavlovskii/Course_BD.git
cd Course_BD
```

### 2. Создание виртуального окружения и установка зависимостей

```aiignore
poetry install
```

### 3. Настройка базы данных PostgreSQL

Убедитесь, что у вас установлен PostgreSQL. Создайте файл .env в корневой директории проекта и добавьте следующие
переменные:

```aiignore
DB_HOST=ваш хост
DB_PORT=ваш порт
DB_USER=имя пользователь
DB_PASSWORD=ваш пароль
```

### 4. Запуск приложения
```aiignore
poetry run python main.py
```

## Использование
1. Запуск приложения: После запуска программа предложит ввести ключевое слово для поиска вакансий.

2. Основное меню: Программа предоставляет несколько опций:

+ Вывести список компаний и количество вакансий

+ Вывести список всех вакансий с указанием зарплаты

+ Показать среднюю зарплату по всем вакансиям

+ Найти вакансии с зарплатой выше средней

+ Найти вакансии по ключевому слову в названии

## Классы и методы
#### `HeadHunterAPI`

+ `get_vacancies(keyword: str) -> list[dict]` - получает вакансии по ключевому слову

#### `DBManager`
+ `get_companies_and_vacancies_count() -> Any` - список компаний и количество вакансий

+ `get_all_vacancies() -> Any` - все вакансии с названием компании и зарплатой

+ `get_avg_salary() -> float` - средняя зарплата по вакансиям

+ `get_vacancies_with_higher_salary(avg_salary: float) -> Any` - вакансии с зарплатой выше средней

+ `get_vacancies_with_keyword(key_word: str) -> Any` - вакансии по ключевому слову

#### `utils.py`
+ `create_database(db_name: str, params: dict)` - создает базу данных

+ `create_table(db_name: str, params: dict) `- создает таблицы

+ `filling_db(db_name: str, params: dict, list_vac: Iterator)` - заполняет таблицу компаний

+ `filling_db_vacancies(db_name: str, params: dict, list_vac: Iterator)` - заполняет таблицу вакансий
